Tokyo Night syntax rules are vendored from Enkia's Tokyo Night VS Code extension
1.1.2, `tokyo-night-storm-color-theme.json` and `tokyo-night-light-color-theme.json`.
Only token colors and semantic token colors are retained. ReviewBox owns its
surfaces, selection, gutter and diff colors. The upstream MIT license is included
in `TOKYO-NIGHT-LICENSE.txt` and in `public/licenses/tokyo-night.txt` so the
packaged application includes the attribution too.
